# Training Java Projects



### 1. Student Management System

A Core Java console-based application for managing student information in a coaching center.

#### Features

- Add student
- Display all students
- Search student by ID
- Search student by name
- Update student marks
- Update attendance
- Calculate grade
- Remove student
- Find topper
- Save student details to a file
- Load student details from a file


#### Concepts Used

- OOP
- Encapsulation
- HashMap
- Enum
- Exception Handling
- Custom Exceptions
- Java Serialization
- File Handling
- Collections

---

### 2. Personal Expense Tracker

A Core Java console-based application for recording and analyzing personal expenses.

#### Features

- Add expense
- Categorize expense
- Delete expense
- Display all expenses
- Calculate total expenses
- Find highest expense
- Calculate category-wise expenses

#### Concepts Used

- ArrayList
- HashMap
- Enum
- Date and Time API
- Stream API
- Exception Handling
- OOP

---

## Technologies

- Java
